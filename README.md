# BT Spatio-Temporal Anomaly Detection

This repository contains the four Jupyter notebooks used to complete the computational workflow for my MSc Data Science and Analytics dissertation.

The notebooks cover:

1. POI data collection and preparation
2. Data cleaning and feature engineering
3. Daily anomaly detection (Model 1)
4. Hourly anomaly detection (Model 2)

Together, the notebooks document the complete workflow from data preparation through to anomaly detection, interpretation and comparison of the daily and hourly analyses.
